Assignment names, for changing one

Changing an assignment means naming it exactly. The ALZ library version-stamps these names, for example Deploy-MDFC-Config-H224, so copy from this list rather than from documentation or a blog post. Edit platform-landing-zone.auto.tfvars in the module repo, keyed by the management group it is assigned at, then open a pull request. The change goes through the same plan, approval, and apply as everything else.

policy_assignments_to_modify = {
  alz = {                                  # the management group below
    policy_assignments = {
      <assignment-name> = {                # copied from this list
        enforcement_mode = "DoNotEnforce"   # stop it acting, keep the compliance signal
        # parameters     = { ... }          # change its settings
        # not_scopes     = [ ... ]          # exempt one scope
        # creation_enabled = false          # remove it (small scale only, see docs)
      }
    }
  }
}
